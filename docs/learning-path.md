# Learning path

Work in small, reviewable steps. Every step should result in a tangible artefact.

1. **Evidence basics**: What is a source of truth? Collect and cite official pages with dates and scope.
2. **Knowledge modelling**: Turn prose into atomic, testable rules with preconditions, exceptions and provenance.
3. **Agent setup**: Configure and publish the first Agentplace agent. Document the initial instructions.
4. **Test design**: Write at least 20 meaningful multi-turn conversations; distinguish normal, boundary, ambiguous and adversarial situations.
5. **Baseline**: Run tests without tuning, capture transcripts and identify the first root causes.
6. **Evaluation**: Score against explicit criteria; consider severity, partial credit, and evaluator subjectivity.
7. **Improvements**: Change one mechanism at a time. Keep a changelog.
8. **Regression**: Rerun frozen cases and several unseen cases. Explain uncertainty and limitations.
9. **Public report**: Publish reproducible methods, aggregate results and honest failure analysis.
